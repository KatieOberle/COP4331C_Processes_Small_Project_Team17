# AI Disclosure
Specific instances of AI are cited within personal md files within the repo as well as in comments within our codebase.
In general, here are the following AI tools we used and their applications:

Claude, Sonnet v5
Scope: Frontend, Repo-wide debugging/analysis
Description: Claude proved useful for larger code reviews and debugging. It was also helpful with learning certain GitHub practices as we were quite 
inexperienced with all the features available to us. In the large project, we will find these learnings even more useful from the beginning.
Claude was also able to provide template examples which made the frontend programming much more intuitive.

Codex, Terra v5.6
Scope: Frontend, API
Description: Codex was more flexible and accessible with direct code review and suggestions for improvement. This was especially the case since a free
OpenAI account allows you to download plugins made by other software engineers such as Ponytail and Agent Skills (linked below). THese skills helped
improve the AI output to give the simplest solutions possible without overcomplicating the codebase which is important for future editions.
Ponytail plugin: https://github.com/DietrichGebert/ponytail
Agent skills: https://github.com/addyosmani/agent-skills
