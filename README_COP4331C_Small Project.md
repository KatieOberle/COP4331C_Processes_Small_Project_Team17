## Official Assignment Directions
Project Description
Your team will design, develop, deploy, and present a Personal Contact Manager web application. Each user on the app must be able to create an account, log in, and manage their own private contacts independently of other users.

# Core Features
Your application must include the following:

User Authentication: Registration (Sign up), Login
Contact Management (per user): Add contacts, edit contacts, delete contacts, search contacts (server-side search required), no shared contacts
Initial page: Users must be able to log in or register when the application loads
Search requirement: You must implement a search API; you may not cache all contacts on the client-side; searchers must query the server and support partial matching

# Technical Requirements 
LAMP (Linux, Apache, MySQL, PHP) stack required
Python-based frameworks are NOT allowed
Must use a remote database

# Hosting and Deployment
Application must be hosted on a remote server
Local demos are NOT allowed
Required hosting options include (but are not limited to): Digital Ocean (strongly recommended), AWS, Azure, Heroku, GoDaddy
Application MUST be accessed via a domain name (IP addresses are not acceptable)
Use JSON for all client-server communication
Web client must be AJAX-enabled (asynchronous API calls required)

# API Requirements
Implement a REST-style API
Demonstrate at least 1 (one) and no more than 2 (two) API end points
API demonstration must be done using SwaggerHub
At least one demonstrated endpoint must be functional during the presentation
